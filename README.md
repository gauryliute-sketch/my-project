# BCRacing.lt landing page

SEO paruoštas statinis landing puslapis domenui **bcracing.lt**.

## Failai
- `index.html` – pagrindinis puslapis su LT turiniu, meta žymomis ir struktūrizuotais duomenimis.
- `styles.css` – puslapio stiliai.
- `robots.txt` – robotų instrukcijos ir sitemap nuoroda.
- `sitemap.xml` – pradinis sitemap Google indeksacijai.

## Lokalus paleidimas
```bash
python3 -m http.server 4173
```

Tada atidarykite `http://localhost:4173`.
